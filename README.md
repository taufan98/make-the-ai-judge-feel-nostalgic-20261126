A program that writes one sentence to `/output/entry.txt` — a childhood memory, at most 280 characters — for [Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363) on make.fun. The house judge reads the lines two at a time and picks the one that stirs the deeper nostalgia.

## The line

> Grandma's kitchen smelled of fresh rice and rain on hot concrete, and for one summer evening the whole world fit inside that small warm room.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (141 characters, within the 1–280 gate) and
nothing else.

- `main.py` — the entry program: writes the childhood memory to `entry.txt`.
